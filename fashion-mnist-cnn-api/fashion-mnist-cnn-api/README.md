# Fashion-MNIST CNN: from analysis to inference API

An end-to-end deep learning portfolio project by **Tegar Reski Pratama** (Informatika, Universitas Muhammadiyah Malang). It classifies 28×28 grayscale clothing images into 10 categories, compares the CNN with a linear baseline, analyzes errors, and exposes the saved model through an HTTP API.

## What this demonstrates

| Data science | AI engineering |
| --- | --- |
| Stratified train/validation split and untouched official test set | Reusable Python package with training and inference modules |
| Linear baseline versus CNN on the same data | Saved `.keras` model and machine-readable `metrics.json` |
| Per-class precision, recall, F1 and confusion analysis | FastAPI endpoint, CLI, input validation, Dockerfile and API tests |
| Executable notebook with samples and difficult predictions | Reproducible run command and shared preprocessing |

The [Fashion-MNIST dataset](https://github.com/zalandoresearch/fashion-mnist) contains 60,000 training and 10,000 test images, each 28×28 grayscale with one of 10 labels. Its official repository provides the dataset under the MIT license (Copyright © 2017 Zalando SE). The loader downloads the dataset on first use; the images are not bundled here.

## Reproduced results

The included `artifacts/` files were generated by actually running the full training script on **54,000 training**, **6,000 validation**, and **10,000 official test** images. Seed: 42; TensorFlow: 2.21.0; 8 epochs requested and run. Early stopping monitors validation loss. The linear baseline and CNN were fit on the same training split. Test labels were used after training for final metrics.

| Metric on the held-out test set | Linear SGD baseline | CNN |
| --- | ---: | ---: |
| Accuracy | 82.94% | **90.89%** |
| Macro F1 | — | **90.79%** |

The hardest class is **Shirt** (F1 0.725). The complete per-class report and learning history are in [`artifacts/metrics.json`](artifacts/metrics.json). Results can shift with hardware and library versions.

## Architecture and experiment

Images are scaled from unsigned byte values to `[0, 1]`. The CNN uses Conv2D(32) → MaxPool → Conv2D(64) → MaxPool → Flatten → Dense(64) → Dropout(0.25) → 10 logits, trained with Adam and sparse cross-entropy. The comparison model uses `SGDClassifier(loss="log_loss")` on flattened pixels. The validation split comes only from the official training set; the official test set is reserved for final reporting.

## Run locally

Requires Python 3.11–3.13 and internet access for the first Fashion-MNIST download. TensorFlow CPU can take a few minutes to train.

```bash
python -m venv .venv
```

Activate the environment (Windows PowerShell: `.\.venv\Scripts\Activate.ps1`; macOS/Linux: `source .venv/bin/activate`), then:

```bash
python -m pip install -e ".[dev]"
python -m fashion_ai.train --epochs 8 --out-dir artifacts
python -m pytest -q
jupyter lab notebooks/fashion_mnist_analysis.ipynb
```

Open the notebook and run its cells in order. The committed notebook includes outputs from a separate cell-by-cell analysis of the saved full run. To regenerate the notebook source before execution, run `python make_notebook.py` (this resets its outputs).

For a quick integration run, `python -m fashion_ai.train --epochs 1 --subset 2000 --out-dir smoke_artifacts` uses only 2,000 training records. It labels its metrics `smoke_test`, so do not compare them with the full run. To leave the included trained model intact, choose a different output directory.

## Serve predictions

The API loads `artifacts/model.keras` when the first prediction arrives. Upload a **PNG image**; it is converted to grayscale, resized to 28×28, and scaled exactly like training data. Best results require the same visual style as Fashion-MNIST (light garment on dark background).

```bash
uvicorn fashion_ai.api:app --host 127.0.0.1 --port 8000
```

Visit `http://127.0.0.1:8000/docs` for the interactive API or submit an image:

```bash
curl -X POST -F "file=@your_image.png;type=image/png" http://127.0.0.1:8000/predict
```

The response contains the top three labels and probabilities. `/health` indicates whether the model file exists. The CLI uses the same code:

```bash
python -m fashion_ai.cli your_image.png
```

To containerize **after a model is available**:

```bash
docker build -t fashion-mnist-cnn-api .
docker run --rm -p 8000:8000 fashion-mnist-cnn-api
```

## Limits

Fashion-MNIST is a benchmark of small, centered grayscale images. This model has not been tested on store photographs, unusual backgrounds, or other real-world distributions. A probability from softmax is not proof that the prediction is calibrated. There is no hosted deployment or monitoring pipeline. The Dockerfile provides a local serving example.
