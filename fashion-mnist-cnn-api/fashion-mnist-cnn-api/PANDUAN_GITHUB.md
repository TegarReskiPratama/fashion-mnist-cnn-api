# Unggah ke GitHub

Nama repository yang disarankan: `fashion-mnist-cnn-api`.

Deskripsi repository:

> End-to-end image classification with TensorFlow CNN, baseline comparison, error analysis, and FastAPI inference.

Topics: `deep-learning`, `computer-vision`, `tensorflow`, `cnn`, `fashion-mnist`, `fastapi`, `data-science`, `machine-learning`.

1. Buat repository **Public** baru pada akun GitHub kamu. Jangan otomatis menambahkan README, `.gitignore`, atau lisensi karena paket ini sudah punya berkasnya.
2. Ekstrak ZIP, kemudian unggah **isi folder** `fashion-mnist-cnn-api` ke root repository lewat **Add file → Upload files**. Jangan hanya unggah ZIP.
3. Pastikan folder `artifacts/` ikut terunggah: `model.keras`, `metrics.json`, dan dua gambar hasil. Ukuran setiap berkas harus di bawah batas unggah melalui browser. Jika Windows tidak menampilkan `.gitignore` atau `.dockerignore`, aktifkan tampilan berkas tersembunyi atau buat melalui GitHub.
4. Tulis commit message `Add Fashion-MNIST CNN and inference API` dan commit. Cek README serta grafik setelah unggah.
5. Jalankan instruksi `Run locally` pada README untuk mereproduksi hasil. Dokumen ini menunjukkan eksperimen benchmark pakaian 28×28, belum merupakan solusi klasifikasi pakaian nyata di dunia produksi.

Kode yang ditulis penulis proyek ini dapat diberi lisensi tersendiri bila diinginkan. Kredit dataset dan lisensi MIT milik Zalando Research tercantum dalam README.
